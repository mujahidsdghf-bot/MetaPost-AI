# 🚀 MetaPost AI

MetaPost AI is a full-stack automated marketing and affiliate revenue generation platform built with Python (FastAPI & Streamlit). It helps users generate AI-powered marketing copies, blog articles, and auto-publish them directly to Instagram and WhatsApp via Meta APIs.

## ✨ Key Features:
- 🤖 **AI Content Generation:** Create catchy ad captions, product descriptions, and full blog posts.
- 📡 **Meta & WhatsApp Auto-Publishing:** Direct integration to post updates and promotional messages automatically.
- 📊 **Analytics & Tracking:** Monitor clicks, conversions, and total earnings.
- 💎 **SaaS Subscription Models:** Built-in pricing tiers for commercial use.

## 🛠️ Tech Stack:
- **Frontend:** Streamlit
- **Backend:** FastAPI (Python)
- **APIs:** Meta Graph API & WhatsApp Cloud API
